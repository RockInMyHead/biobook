# БиоЛаб Журнал — основные функции

**Продукт:** Bio-Notebook (БиоЛаб Журнал) · **Антикусь**  
**Прод:** [anticus.tech/bio-notebook](https://anticus.tech/bio-notebook/)  
**Связанный материал для клиентов:** [BIOLAB-ZHURNAL.md](./BIOLAB-ZHURNAL.md)

Документ описывает **что умеет система** с точки зрения пользователя и администратора. Технический деплой — в [deploy.md](./deploy.md).

---

## 1. Ядро: эксперименты и записи

| Функция | Описание |
|--------|----------|
| **Эксперимент** | Отдельный исследовательский «проект»: протокол, данные, файлы в одном месте. |
| **Узлы (nodes)** | Древовидная структура записей — ветки, этапы, повторы опыта, выводы. |
| **Редактор узла** | Текст, вложения, сохранение с автосинхронизацией через API. |
| **Дашборд** | Список экспериментов пользователя, быстрый вход в работу. |
| **Публичная ссылка** | Включение/выключение публичного просмотра эксперимента и отдельных узлов (`/share/...`). |
| **Wiki эксперимента** | Внутренняя вики-страницы по эксперименту (создание, редактирование, список страниц). |
| **Файлы эксперимента** | Централизованное хранилище файлов эксперимента: загрузка, скачивание, удаление. |
| **Граф связей** | Визуализация связей между экспериментами/узлами (если включено на сервере). |

---

## 2. Запись данных: текст, код, медиа

| Функция | Описание |
|--------|----------|
| **Загрузка файлов** | Прикрепление изображений и документов к узлам и в хранилище эксперимента. |
| **OCR** | Распознавание текста с фото рукописных/печатных записей → вставка в журнал. |
| **Голос (STT)** | Распознавание речи → текст в запись (удобно у стенда). |
| **Python-ячейки** | Выполнение кода в изолированном kernel: расчёты, таблицы, графики. |
| **Автодополнение кода** | Подсказки при вводе в Python-ячейке. |
| **Версии узла** | Создание снимков содержимого, просмотр истории, откат к прошлой версии. |
| **Экспорт DOCX** | Выгрузка содержимого узла в Word для отчётов и сдачи работ. |

## 3. ИИ-ассистент

| Функция | Описание |
|--------|----------|
| **Чат по записи** | Диалог в контексте текущего эксперимента/узла (текст, HTML-фрагмент, заметки). |
| **Сброс чата** | Очистка истории диалога ассистента по узлу. |
| **Планировщик (planner)** | Отдельный сценарий: чат и создание структуры/плана работ (API planner). |

*На проде модель и ключ задаются в окружении сервера (`AI_API_*`).*

## 4. Лаборатория повседневности

| Модуль | Функции |
|--------|---------|
| **Реагенты** | Список, остатки, добавление и изменение позиций. |
| **Расходники** | Учёт consumables (аналогично реагентам). |
| **Оборудование** | Каталог приборов, бронирование слотов. |
| | Согласование/отклонение брони, завершение, отмена. |
| | Просмотр календаря/списка бронирований. |
| **Проекты** | Управление проектами, задачами, участниками, приглашениями по коду. |
| | Диаграмма Ганта по проекту (`/api/project/{id}/gantt`). |

## 5. Коллаборация и социальный слой

| Функция | Описание |
|--------|----------|
| **Друзья** | Заявки, принятие/отклонение, удаление из списка. |
| **Профили** | Публичная страница пользователя `/profile/{username}`. |
| **Личные чаты** | Создание чатов, сообщения, прочитано/непрочитано, сводка непрочитанного. |

## 7. Lab Admin (серверная админка)

Отдельный вход **не через логин пользователя**, а через ключ `ADMIN_KEY`.

| URL (под префиксом `/bio-notebook`) | Назначение |
|--------------------------------------|------------|
| `/lab-admin` | Вход по ключу. |
| `/lab-admin/dashboard` | Дашборд: пользователи, метрики, активность. |

**Возможности админки (обзор):**

- просмотр и редактирование пользователей, массовые операции;
- удаление пользователей и экспериментов;
- корпоративные клиенты и организации;
- реферальные коды;
- тикеты поддержки (ответы, смена статуса);
- журнал аудита / логи, аналитика;
- экспорт пользователей;
- вход «как пользователь» (login as) для поддержки.

Старый путь `/admin` перенаправляется на `/lab-admin`.

## 8. Тарифы (логика продукта)

| План | Для кого | Ключевые отличия (ориентир) |
|------|----------|-----------------------------|
| **free** | Пробный старт | Ограниченное число экспериментов, базовый функционал. |
| **student** | Студент / преподаватель | Полный OCR, голос, отчёты, ИИ, больший объём. |
| **corp** | Лаборатория / вуз | Командная работа, расширенные лимиты, сопровождение по договору. |

Точные лимиты и цены на витрине — [BIOLAB-ZHURNAL.md](./BIOLAB-ZHURNAL.md) и страница pricing в продукте.

## 10. Что это **не** заменяет

- Не является СЭД или полноценной LIMS «из коробки» для всей лаборатории — фокус на **журнале исследования**, учёте и коллаборации вокруг него.
- ИИ даёт подсказки и черновики; ответственность за научную корректность остаётся за автором записи.

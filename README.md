# Био-Блокнот (SAAS Решение)

Это базовая сборка среды для специалистов по биоинформатике, ориентированная на локальное использование LLM и векторных баз данных. Система предоставляет веб-интерфейс для управления экспериментами и данными.

## Включенные компоненты
1. **Управление проектами**: Веб-приложение на FastAPI для организации рабочих директорий.
2. **LLM и RAG**:
   - `Ollama` (локальный запуск LLM, доступен через http://ollama:11434).
   - `LangChain` (инструменты для RAG-приложений).
   - `Milvus` (Standalone Векторная база данных, порт 19530).

## Как запустить

1. **Сборка и запуск контейнеров**
   ```bash
   cd ./bio-notebook
   docker-compose up --build -d
   ```

2. **Доступ к Панели Управления**
   Откройте браузер по адресу: `http://localhost:3000`. 
   Здесь вы можете создавать новые эксперименты, которые будут автоматически организованы в папке `notebooks`.

3. **Работа с локальной LLM**
   Перед использованием модели её нужно скачать внутрь контейнера Ollama:
   ```bash
   docker exec -it <имя_контейнера_ollama> ollama run llama3
   ```
   (замените `llama3` на любую другую модель, например `mistral` или `phi3`).

## Структура данных
Все данные экспериментов сохраняются в локальной папке `./notebooks`, которая монтируется в контейнеры. Вы можете обращаться к этим данным напрямую или через API LangChain/Milvus.
